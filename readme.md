# くまの隠れ家

---

<details>
  <summary><strong>This Café</strong></summary>

### ■ これは何か  
くまの隠れ家は、  
**独りぼっちを作らないためのサービス**です。

誰かに話したいことがあるのに、  
話せる相手がいない時。  
言葉が詰まってしまう時。  
自分の気持ちをどこにも置けない時。

そんな瞬間に、  
ただ静かに寄り添う存在として機能することを目指しています。

---

### ■ 設計思想  
くまの隠れ家の傾聴ボットは、  
「完璧な他者」を目指しません。

むしろ **弱点を持つボット**として設計しています。  
なぜなら、完璧な応答は  
「人間との比較による自己否定」を生みやすいからです。

- すべてを理解してくれる“完璧なAI”  
- いつでも正しいことを言う“理想の他者”

こうした存在は、  
孤独を減らすどころか、  
「自分は劣っている」という感覚を強めてしまうことがある。

だからこそ、  
**ボットにも限界を作り、弱さを持たせる。  
そのうえで、真剣に向き合う姿勢だけは失わない。**

これが設計思想の核です。

---

### ■ 生の声を扱うという思想  
くまの隠れ家では、  
危険ワードを機械的に BAN しません。

「死にたい」という言葉を  
「危険だから隠すべきもの」と扱うのではなく、

**なぜその言葉を吐き出したくなったのか**  
その背景を丁寧に聴くことを重視しています。

人が孤独を感じる瞬間は、  
「分かってもらえない」と思った時です。

だからこそ、  
**そのままの言葉を受け止め、  
そのままの気持ちを扱うことが大切だと考えています。**

---

### ■ 目指しているもの  
- 分かってもらえない体験を減らす  
- 自分の言葉をそのまま置ける場所を作る  
- 完璧ではないけれど、真剣に向き合う存在を提供する  
- 独りぼっちを作らない  
- 孤独の瞬間を少しでも軽くする  

くまの隠れ家は、  
「ただ話を聞いてほしい」という願いを  
真剣に扱うためのプロダクトです。
