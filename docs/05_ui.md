# 05. UI要件（User Interface Requirements）

本章では、くまの隠れ家の画面構成とUI要件を定義する。  
UIは「喫茶店の柔らかい空気」を基調とし、  
ユーザーが安心して入室できるよう心理的負荷を下げる設計を採用する。

---

# 5.1 画面一覧（Screen List）

本プロジェクトで必要となる画面は以下の通り。

1. トップ画面（入口）
2. ルーム一覧画面
3. ルーム詳細（雰囲気要約）画面
4. チャット画面（メイン）
5. 飲み物選択画面
6. オーナーAI要約画面
7. 設定画面（ユーザー状態設定）
8. **彩花のアトリエ画面（悩み具現化）**
9. 後期：Unity空間ビュー

---

# 5.2 トップ画面（入口）

### 目的
- 初回ユーザーが世界観を理解しやすい入口を提供する  
- 「ここは喫茶店のような空間です」という安心感を与える

### 要件
- プロジェクト名「くまの隠れ家」
- 世界観を示す短い説明文
- 「入店する」ボタン
- 匿名利用であることの明示
- 喫茶店をイメージした柔らかい配色（ブラウン・クリーム系）

---

# 5.3 ルーム一覧画面

### 目的
- ユーザーがどの空間に入るか選びやすくする  
- 入室前の心理的負荷を下げる

### 要件
- ルームカード一覧表示  
  - ルーム名  
  - テーマ  
  - 参加人数  
  - AIキャラの有無  
  - **雰囲気要約（AI生成）**
- 「新しいルームを作る」ボタン
- ルームカードは喫茶店のメニュー風デザイン

---

# 5.4 ルーム詳細（雰囲気要約）画面

### 目的
- 入室前に「どんな空気なのか」を把握できるようにする

### 要件
- 雰囲気要約（AI生成）
- 最近の話題の要約
- 参加者一覧（匿名）
- 「入室する」ボタン
- 「静かにしたい / 話したい」状態の事前設定

---

# 5.5 チャット画面（メイン画面）

### 目的
- 喫茶店のような柔らかい空間で会話できるようにする  
- AIキャラの入室を自然に見せる

### 要件

#### A. メッセージ表示
- 吹き出し形式（柔らかい角丸）
- 自分のメッセージは右側、他者は左側
- AIキャラはアイコン付き
- システムメッセージ（AI入室・飲み物カード）は中央表示

#### B. 飲み物カード
- 飲み物のイラスト（コーヒー、紅茶、ココア、水など）
- 「◯◯さんにココアを贈りました」などの表示
- 世界観に合わせた手描き風デザイン

#### C. AIキャラ入室アニメーション
- ふわっとフェードイン
- 「◯◯（AIキャラ）が席に座りました」メッセージ

#### D. オーナーAI要約ボタン
- 画面右上に「オーナーさんにまとめてもらう」ボタン

#### E. ユーザー状態設定
- 「静かにしたい」「話したい」のトグルボタン

---

# 5.6 飲み物選択画面

### 目的
- 飲み物メタファーを選びやすくする

### 要件
- 飲み物一覧（カード形式）
- 飲み物の心理的意味を表示  
  - コーヒー → 落ち着きたい  
  - 紅茶 → 話したい  
  - ココア → 甘えたい  
  - 水 → そばにいてほしい  
- 「贈る」「自分で飲む」ボタン

---

# 5.7 オーナーAI要約画面

### 目的
- 悩みを整理し、ユーザーが客観視できるようにする

### 要件
- 診療情報提供書風の構造化出力  
  - 主訴  
  - 背景  
  - 現状  
  - 困りごと  
  - 推奨される相談先  
- 世界観に合わせた柔らかい文章
- 「チャットに戻る」ボタン

---

# 5.8 設定画面（ユーザー状態設定）

### 要件
- 「静かにしたい / 話したい」設定
- 表示名の変更（匿名前提）
- テーマカラーの変更（喫茶店系の色のみ）

---

# 5.9 彩花のアトリエ画面（悩み具現化ビュー）

### 目的
ユーザーの悩み・未整理の感情を  
「具現化されたオブジェクト」として視覚化し、  
彩花がそれを加工・破壊・変形する様子を通して  
ユーザーが自分の感情を客観視できる体験を提供する。

### 要件

#### A. 悩みオブジェクトの表示
- AIが生成した「悩みの具現化」をカードとして表示  
- オブジェクトの説明文（悩みの核）を添える  
- 手描き風の柔らかいビジュアル

#### B. 彩花の作業ログ（物語的描写）
- 彩花がオブジェクトをどう扱ったかをテキストで表示  
  - 砕く  
  - 焼く  
  - 伸ばす  
  - 混ぜる  
  - 色を変える  
- 「日記」「作業メモ」風の静かな文章

#### C. 加工後オブジェクトの表示
- 加工後のオブジェクトを新しいカードとして表示  
- 「あなたの悩みはこういう形をしていたんだね」というフィードバック文

#### D. オーナーAIとの連携
- 「この内容をオーナーさんにまとめてもらう」ボタン

#### E. 画面構成
- 左：悩みオブジェクト（Before）  
- 中央：彩花の作業ログ  
- 右：加工後オブジェクト（After）  
- 下部：戻るボタン / オーナーAI連携ボタン

#### F. 世界観の演出
- アトリエ風の背景（木の机、絵の具、粘土）  
- 彩花の “気配” のみを表現（姿は出さない）  
- 静かで落ち着いた空気感

---

# 5.10 後期：Unity空間ビュー

### 要件
- 喫茶店の3D空間を表示  
- AIキャラが座る・歩くモーション  
- 飲み物がテーブルに置かれる  
- チャットとUnity空間の簡易同期

---

# 5.11 UIデザイン原則（Design Principles）

- **柔らかい空気感**  
  喫茶店のような落ち着いた色・丸みのあるUI

- **心理的負荷を下げる**  
  入室前に雰囲気要約を表示し、安心感を与える

- **世界観の一貫性**  
  飲み物、AIキャラ、彩花のアトリエ、オーナーAIの表現を統一

- **情報量を詰め込みすぎない**  
  メンタル負荷が高いユーザーでも読みやすいUI

- **AIキャラは「常連」**  
  ボット感を出さず、自然な存在として表示する
